# 🛡️ SHUJAA-SOC LITE
Community Cyber Defense HelpDesk for Eldoret SMEs & Schools

**EldoHub Buildathon 2026 - Building at the Edge of Possibility**

### The Problem
Small businesses, schools & cybercafes in Eldoret face daily cyber threats but can't afford a SOC team.

### The Solution
An AI-powered IT Support + SOC Lite dashboard:
- 🎫 IT Helpdesk Ticketing (Printer, Slow PC, Email issues)
- 🔍 Upload logs/pcap -> Auto-detect threats (Hiloti Dropper IOCs)
- 🚫 Auto-generate blocklist
- 🇰🇪 English/Swahili

**Stack:** Python Flask + HTML/JS + SQLite
**Team:** Stephen Otiende + AI Tech Partner
